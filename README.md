# Caesar Cipher 🔐

My first Python encryption project.

## What it does

This program can:

- Encode a message using a Caesar Cipher
- Decode a message using a Caesar Cipher
- Shift letters by a specified number

## Example

If the message is:

hello

and the shift is:

3

The encoded result is:

khoor
